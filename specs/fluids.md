# Fluid Capacities and Specifications

All specifications are for the **2005 Mondeo Mk3 Estate 2.2 TDCi**.
Always use the Ford WSS specification number when purchasing fluids - the grade alone is not sufficient.

## Engine Oil

| Parameter | Value |
|---|---|
| Capacity (with filter) | ~6.2 L |
| Grade | SAE 5W-30 |
| Ford specification | WSS-M2C913-C (preferred), also accepts -B or -D |
| Drain plug torque | 23 Nm |
| Change interval | 12 months or 15,000 km (whichever comes first) |

### Notes
- Always replace the oil filter at every oil change
- Use a new crush washer on the drain plug each time
- Allow the engine to warm up before draining for more complete evacuation
- Overfilling diesel engines is particularly harmful - check dipstick after filling to ~5.8 L, then top up

## Gearbox Oil

| Parameter | Value |
|---|---|
| Gearbox type | Getrag M66 (6-speed manual) |
| Capacity | 2.0 L |
| Grade | SAE 75W-90 (fully synthetic) |
| Ford specification | WSS-M2C200-C3 |

### Notes
- Ford considers gearbox oil "lifetime fill" but many owners change it at ~100,000 km
- The fill and drain plugs are Allen/hex key type
- Fill from the level plug hole until oil runs out - that gives the correct level

## Coolant / Antifreeze

| Parameter | Value |
|---|---|
| System capacity | ~8-9 L (total system) |
| Coolant type | OAT (Organic Acid Technology), red/orange colour |
| Ford specification | WSS-M97B44-D |
| Mixture | 50/50 coolant to distilled water |
| Change interval | 10 years or 240,000 km (Ford long-life coolant) |
| Thermostat opening temp | ~82°C |

### Notes
- **Never mix OAT (red) with silicate-based (green/blue) coolant** - it forms a gel that blocks passages
- If unsure what is in the system, flush completely before refilling
- The system has a bleed screw - use it to avoid air locks after refilling
- Check coolant level when engine is cold

## Brake Fluid

| Parameter | Value |
|---|---|
| Type | DOT 4 |
| Ford specification | WSS-M6C65-A2 |
| Change interval | Every 2 years (hygroscopic - absorbs moisture over time) |

### Notes
- Brake fluid is hygroscopic - it absorbs moisture from the air, lowering its boiling point
- Old brake fluid can cause brake fade under heavy use and corrode internal brake components
- Use a syringe or turkey baster to remove old fluid from the reservoir before bleeding

## Power Steering Fluid

| Parameter | Value |
|---|---|
| Type | ATF (Automatic Transmission Fluid) - Mercon V compatible |
| Ford specification | WSS-M2C204-A2 |

### Notes
- Check level with engine off
- Low fluid usually indicates a leak - inspect hoses and rack seals

## Diesel Fuel

| Parameter | Value |
|---|---|
| Tank capacity | 59 L |
| Fuel type | EN 590 diesel |
| Estimated range | ~910 km per tank |

### Notes
- Running completely dry requires bleeding the fuel system to restart
- In cold climates, use winter-grade diesel or add anti-wax additive below -10°C
- The fuel filter should be changed at every major service (~30,000 km)

## Washer Fluid

| Parameter | Value |
|---|---|
| Front reservoir capacity | ~3.5 L (shared with rear on estate) |
| Type | Screen wash concentrate mixed with water |

### Notes
- In winter, use a mix rated to at least -20°C to prevent freezing in the lines and pump
